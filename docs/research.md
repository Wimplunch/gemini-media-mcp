# Research notes

Checked on **2026-10-31** against the official documentation at ai.google.dev and the
installed SDK sources. Prices change; re-check before relying on them.

## Gemini API: image models ("Nano Banana" family)

Source: <https://ai.google.dev/gemini-api/docs/image-generation>,
<https://ai.google.dev/gemini-api/docs/models>, <https://ai.google.dev/gemini-api/docs/pricing>
(pricing page "Last updated 2026-10-30 UTC").

| Model ID | Name | Input (USD / 1M tok) | Output per image | Sizes |
|---|---|---|---|---|
| `gemini-nano-banana-2.1` | Nano Banana 2.1 (newest, recommended default) | 1.50 | 1K $0.0336 · 2K $0.0504 · 4K $0.113 | 1K, 2K, 4K |
| `gemini-3.1-flash-lite-image` | Nano Banana 2 Lite (cheapest, fastest) | 0.25 | 1K $0.0336 | 1K |
| `gemini-3.1-flash-image` | Nano Banana 2 | 0.50 | 512 $0.045 · 1K $0.067 · 2K $0.101 · 4K $0.151 | 512, 1K, 2K, 4K |
| `gemini-3-pro-image` | Nano Banana Pro | 2.00 | 1K/2K $0.134 · 4K $0.24 | 1K, 2K, 4K |
| `gemini-2.5-flash-image` | Nano Banana (legacy, limited to existing users, shutdown 2027-03-15) | 0.30 | $0.039 | 1K |

- No free tier for any image model.
- Aspect ratios: 1:1, 2:3, 3:2, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9 (SDK also knows 1:8, 8:1, 1:4, 4:1).
- Image sizes must use uppercase `K`; the SDK literal for 0.5K is `"512"`.
- Reference images: up to 14 in total (per-type limits differ per model: objects, characters, styles).
- Input MIME types accepted by the SDK: png, jpeg, webp, heic, heif, gif, bmp, tiff.
- "All generated images include a SynthID watermark."
- Imagen 4 is shut down on the Gemini API.

**API surface.** The docs now use the *Interactions API*:
`client.interactions.create(model=..., input=..., response_format={"type": "image", "aspect_ratio": ..., "image_size": ...})`,
result bytes in `interaction.output_image.data` (base64). Requires `google-genai >= 2.3.0`.
The API key is sent as the `x-goog-api-key` header (not in the URL).

## Video: Veo is gone from the Gemini API

Source: <https://ai.google.dev/gemini-api/docs/veo>, <https://ai.google.dev/gemini-api/docs/omni>.

- `veo-3.1-generate-preview`, `veo-3.1-fast-generate-preview` and `veo-3.1-lite-generate-preview`
  were **shut down on 2026-10-22**. `veo-3.0-*` is deprecated. GA Veo exists only on Google Cloud
  (Gemini Enterprise Agent Platform), which needs a GCP project instead of an API key.
- Google's recommended replacement is **Gemini Omni Flash, `gemini-omni-1.1-flash`**.
- Pricing: output $17.50 / 1M tokens, billed at 5,792 tokens per second of 720p video, i.e.
  **about $0.10 per second**. Input $1.50 / 1M tokens. No free tier. No separate prices for
  360p / 1080p / 4K are published (1080p and 4K are "upscaled").
- Video config (`response_format`): `type="video"`, `aspect_ratio` 16:9 | 9:16, `resolution`
  360p | 720p | 1080p | 4k. A start frame is passed as an image part in `input`.
  Single generations are short (extensions add 3–10 s, up to 40 s total). Audio is generated by default.
- Long runs: `background=True` (requires `store=True`) returns an interaction ID immediately;
  `client.interactions.get(id)` returns status (`queued`, `in_progress`, `completed`, `failed`,
  `cancelled`, `incomplete`, `budget_exceeded`, …) and, when done, the video inline as base64.
- "All generated videos include SynthID watermarking."

**Decision.** The video tools (`start_video`, `get_video_status`) are model-agnostic and default
to `gemini-omni-1.1-flash`. The cost estimate assumes 10 s (the maximum single-generation
length) so the budget check errs on the expensive side. 1080p/4K are disabled by default
because Google publishes no price for them; they can be enabled in a config file.

## MCP Python SDK

- Current release `mcp==2.3.0` (2026-10-02). In mcp 2.x **`FastMCP` was renamed to
  `MCPServer`** (`from mcp.server.mcpserver import MCPServer`); the decorator API
  (`@server.tool()`) is unchanged. `ToolError` returns a clean `is_error=True` result.
- The SDK depends on `opentelemetry-api` only (no exporter, no SDK), so it emits no telemetry.

## Claude Code / Claude Desktop registration

- Claude Code 2.1.x:
  `claude mcp add --scope user gemini-media -e KEY=value -- uvx gemini-media-mcp`
  (`-s/--scope local|user|project`, `-e/--env`, `--` before the server command).
  `.mcp.json`/user config supports `${VAR}` expansion, so the key can stay a reference.
- Claude Desktop: `~/.config/Claude/claude_desktop_config.json` (Linux),
  `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS),
  `%APPDATA%\Claude\claude_desktop_config.json` (Windows):
  `{"mcpServers": {"gemini-media": {"command": "uvx", "args": ["gemini-media-mcp"], "env": {...}}}}`.
